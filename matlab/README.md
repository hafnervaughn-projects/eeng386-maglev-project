# MATLAB / Simulink

Run `lift_sweep` in MATLAB from this folder. It uses base MATLAB and exports a labeled PNG and CSV to `figures/lift-sweep/`. It checks pressure/coenergy agreement and expected force scaling before exporting.

This is an original static parameter sweep of the illustrative model in [LIFT_MODEL.md](../analysis/LIFT_MODEL.md), not a dynamic simulation or validated Shanghai model. See [PARAMETERS.md](../analysis/PARAMETERS.md) for missing real parameters and interpretation.
