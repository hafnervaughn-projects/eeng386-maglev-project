## What we need to deliver

1. PowerPoint/PDF slides and an in-class presentation with Q&A, **under 15 minutes total**.
2. At least two specific course concepts, correctly applied equations, and a quantitative analysis with assumptions and labeled results.
3. An ambiguity discussion: alternatives considered, why we chose our approach, and reflection.
4. Slides delivered according to instructor instructions before the presentation; see the requirements file for the two submission instructions.
5. Teammate evaluation after presentations, when posted in Canvas.

The project is worth 20% of the course grade. Original simulation or experimental data can earn up to +1% of the course grade.

## How to contribute

Use the live Word document for shared writing. Use this repository for code, calculations, figures, presentation versions, and task tracking. Add your name to an unassigned role after agreeing with the team. Use Issues for tasks and questions; include the deliverable and link the result when finished.

For code changes, create a branch, commit the change, and open a pull request for another teammate to check. Small documentation edits can be made using GitHub's pencil button. Avoid simultaneous edits to the same PowerPoint file; coordinate in the shared document.
