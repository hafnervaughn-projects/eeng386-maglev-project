# Illustrative lift sweep

Generated by `matlab/lift_sweep.m` using the assumptions in `analysis/LIFT_MODEL.md`. Run with base MATLAB; no extra toolboxes are required.

- `lift_sweep.png`: force versus each air gap at three currents; equilibrium current versus gap.
- `lift_sweep.csv`: the same numerical sweep in SI-derived units specified in column names (gap in mm, force in N, current in A).

The nominal example supports 100 kg at a 10 mm gap with approximately 11.176 A. These are classroom assumptions, not Shanghai hardware data. The fixed-current force curves illustrate the destabilizing gap dependence. The equilibrium-current curve does not implement a controller.

Verification: equilibrium force, pressure/coenergy agreement, doubling-current force scaling, and doubling-gap force scaling are checked by assertions in the script. The exported CSV is model output, not experimental data.
